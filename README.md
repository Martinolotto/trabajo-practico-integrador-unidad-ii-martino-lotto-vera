Descripción del Proyecto

Este proyecto consiste en el desarrollo de un sitio web institucional para el Instituto Politécnico Formosa. La página ha sido diseñada para proporcionar información clara y accesible sobre la oferta académica y la identidad de la institución, utilizando tecnologías modernas de desarrollo web.  
Tecnologías Utilizadas

    HTML5: Para la estructura semántica del sitio.  

    CSS3: Para los estilos personalizados y diseño visual.  

    Bootstrap 5.3: Para asegurar que el sitio sea responsivo y utilizar componentes como el carrusel, las cards y el sistema de grillas.  

    Git/GitHub: Para el control de versiones y gestión de ramas durante el desarrollo.  

Estructura del Sitio

El sitio web está compuesto por las siguientes secciones:

    Inicio (index.html): Presentación institucional con carrusel de imágenes.  

    Carreras (carreras.html): Detalle de las tecnicaturas, duración y requisitos de inscripción.  

    Institucional (institucional.html): Historia, misión, visión y autoridades del IPF.  

    Contacto (contacto.html): Formulario de consulta, datos de contacto, ubicación con mapa integrado y sección de preguntas frecuentes (FAQ).  

Instalación y Visualización

Para visualizar el proyecto localmente, simplemente se debe clonar el repositorio y abrir el archivo index.html en cualquier navegador web moderno.
